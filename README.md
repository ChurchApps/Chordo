# Chordo: Chords Manager

![Chordo: Chords Manager](./public/og-image.jpg)

> Organize, transpose, annotate, and view chord sheets

### Features

- Import Text / ChordPro
- Import Images / PDFs
- Import any URL (auto parse chords/lyrics)
- Create setlists
- Share with others

### Run locally

- `npm install`
- `npm run dev`
